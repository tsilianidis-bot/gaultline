## What changed

The same six-domain architecture now surrounds a larger layered SVG Core with restrained mineral-cyan/silver illumination, calibrated source-state segments, stronger numerical hierarchy and deliberately inactive unavailable inputs. The Pressure Index ring displays only its supplied numerical value, not confidence. Organizational connections, admitted associations and upstream-supported causal relationships are visually distinct; retained historical relationships are muted rather than presented as current. No particles, spinning activity or continuous render loop was added.

The interpretation section identifies current supporting domains and records factual snapshot changes. Genuine source admissions, updated observations, supported relationships, verified regime/pressure changes and actual source deadlines produce finite responses. First-load, replayed, incomplete, out-of-order, future or degraded current claims do not create fake market activity. Reduced motion retains the factual text without animation. The existing five destinations are unchanged; their methodology reads REALITY → CAUSATION → CONSEQUENCE → VERIFICATION → ACTION.

Mobile uses a larger independently framed aperture above its touch matrix. Drawer source facts, semantic timestamps, focus restoration and panel/scenario navigation are more readable, while A/B/C semantics, invalidations, Track Record cohorts, thresholds and honest empty states remain intact.

## Integration boundary

[Read the concise refinement handoff](REFINEMENT_HANDOFF.md). No typed fields or host props changed. The only existing-adapter change preserves stale historical domain context when every complete admitted reference has a valid, actually elapsed source deadline. It does not restore current assessments, directions, pressure or regime. Missing, mixed, unadmitted or unproven expiry references still fail closed. Expiry cues require the same source, observation and deadline across snapshots.

Canonical market calculations, Pressure Index methodology, provider adapters, credentials, schedules, billing/Stripe/registration, schema/migrations, production flags and Grok’s ongoing Core/Track Record/checkout work were not modified. The visual component remains outside the production app import graph. Review this draft before any integration or deployment.
