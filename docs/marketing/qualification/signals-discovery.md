Parent reports no authorized nonproduction Polygon configuration and saved secrets are unavailable. The required resource is an **explicitly authorized isolated nonproduction runtime with a nonproduction `POLYGON_API_KEY`, permitted Yahoo/Polygon egress, and a successful current quote response**. It must not be production/Railway and must not substitute any fixture/cache/fallback.
2. **Signals computation access:** the only desktop computed-signal procedure is Core-gated. Because this task prohibits login, no desktop screenshot may claim a computed BUY/SELL/HOLD signal. The Signal Detail path also requires a Core session. A raw public quote capture is narrower than the requested operational Signals claim.

The required resource is an **explicitly approved isolated nonproduction runtime with a source-backed canonical state and provider observations plus authorized nonproduction Forge gateway configuration**; it needs a real non-demo interaction path that does not require login. No such persisted observation or public non-demo UI route is established here.
4. **Separate open PR dependency:** only PR 106 was directly relevant. Its head `1d605757234acc7d36ba7dc9cd5576baa3217d92` changes Yahoo completed-daily-bar filtering (reviewed by `git show`; `server/yahooProxy.ts` hunk) and therefore Signal Detail input integrity. It is **not an ancestor** of this candidate (common base `f908e04ff265d004488f92a909cba4b2e0cebe3b`), so a capture on this candidate cannot claim PR 106 behavior.
